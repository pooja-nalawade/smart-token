# 3-minute demo script

## 1. Patient side
- Open landing page.
- Click Patient Registration / Login.
- Enter name, location, phone and email.
- Select Gynaecology.
- Search by locality/PIN or hospital name.
- Select hospital.
- Confirm date/time.
- Show generated token, estimated wait, suggested arrival and email/SMS notification simulation.

## 2. Admin side
- Return to landing page.
- Click Hospital Admin.
- Use demo code SMT-MUM-001.
- Show four department queues.

## 3. Cancellation event
- Click Patient cancellation.
- Choose a department and token.
- Apply event.
- Show queue moving forward and ETA recalculation.

## 4. Emergency event
- Click Emergency walk-in.
- Select department.
- Enter 20 minutes.
- Apply.
- Show priority insertion and affected ETAs.

## 5. Doctor unavailable
- Click Doctor unavailable.
- Select department and alternative doctor.
- Apply.
- Show doctor name changed and patient notification log.

## Main pitch
"The important part is not just issuing a token. The important part is keeping the ETA alive. Whenever the real-world queue changes, SmartToken re-forecasts the affected patients and communicates the new turn time."
